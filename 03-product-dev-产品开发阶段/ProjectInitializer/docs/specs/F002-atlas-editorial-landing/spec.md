## 验收标准

### AC-F002-001 · 查看第 1 页视觉布局与色彩字体

- 来源：PSC-005, PSC-008
- Given 用户打开应用首屏
- When 查看第 1 页视觉布局与色彩字体
- Then 页面采用暖纸白 #FAF9F6 画布、深墨绿黑 #17201B 主文字、修长衬线标题 × 等宽编号 W01..W03 × 无衬线说明，无渐变发光与装饰 Emoji

### AC-F002-002 · 触发分类过滤

- 来源：PSC-005
- Given 用户点击画册分类筛选胶囊（全部方案 / 设计+开发联动 / 产品设计专精 / FDE 工程交付）
- When 触发分类过滤
- Then 激活胶囊切换为深墨实心底配浅纸字，下方 16:10 画册卡片列表即时过滤显示对应方案

### AC-F002-003 · 触发 applyPreset 动作

- 来源：PSC-001, PSC-002, PSC-005
- Given 用户点击 W01、W02 或 W03 任一方案卡片（或快捷直达按钮）
- When 触发 applyPreset 动作
- Then 原子更新 presetId、selectedStages 与 devMode 并平滑进入第 2 页全局配置（或直达第 3 页目录工作台）
