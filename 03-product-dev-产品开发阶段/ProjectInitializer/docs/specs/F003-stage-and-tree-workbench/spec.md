# F003 · 全局配置与树形轻编辑实时预览工作台规格

## 目标与可观察结果

提供第 2 页全局配置（语言、主力 Agent、五阶段、双模式横幅与手动开关、可选元信息、JSON 导入导出）和第 3 页左树轻编辑与右栏实时预览工作台。

## 来源与范围

- 来源总规格：PSC-001, PSC-002, PSC-003, PSC-004, PSC-006, PSC-008
- 上游设计交接：`../Raw/HANDOFF.md`
- 本 Feature 包含：提供第 2 页全局配置（语言、主力 Agent、五阶段、双模式横幅与手动开关、可选元信息、JSON 导入导出）和第 3 页左树轻编辑与右栏实时预览工作台。
- 本 Feature 不包含：不属于本模块的跨层职责或任何在线 LLM 调用。

## 用户旅程与状态

| 入口/前置 | 用户动作或调用触发 | 过程与反馈 | 对象状态变化 | 可观察结果 | 下一步/消费方 |
|---|---|---|---|---|---|
| 应用已加载 | 触发 F003 核心操作 | 纯函数计算并更新响应式状态 | `ProjectInitConfig` / `ResolvedArtifactBundle` 同步 | 界面预览或导出产物即时呈现 | 下游模块或本地 Agent |

## 功能行为

严格按照 `../Raw/业务PRD.md` 与对应页面 Demo 版 PRD 实现确定性状态流转与视图渲染。

## 异常与恢复

| 情况 | 使用者/消费方可观察状态 | 系统行为 | 恢复/重试 |
|---|---|---|---|
| 非法输入或受限沙箱环境 | 显示明确中文提示或启用沙箱逃生舱 | 拦截非法变更，保留已有配置状态 | 重新选择有效项或复制沙箱脚本 |

## 验收标准

### AC-F003-001 · 更新全局 ProjectInitConfig

- 来源：PSC-001, PSC-002, PSC-003
- Given 用户在第 2 页修改语言、主力 Agent、五阶段勾选或手动切换开发精简模式，并填写可选项目信息
- When 更新全局 ProjectInitConfig
- Then 至少保留 1 个阶段（防空保护 EX-01）；双模式状态横幅准确反映 6 技能精简模式或 12 技能完整模式；主力 Agent 切换准确决定 .agents/rules/ 与 .antigravityignore 生成

### AC-F003-002 · 触发树节点突变操作

- 来源：PSC-003, PSC-004, PSC-006
- Given 用户在第 3 页左栏勾选/取消节点、点击上移/下移调整同级顺序、或新增/重命名自定义节点
- When 触发树节点突变操作
- Then UI 勾选树隐藏 3 级 README.md 与 .gitkeep；锁定节点不可取消（EX-02）；同级 numbered:true 目录序号实时从 1- 重排；右栏完整目录树与 AGENTS.md 索引表同步刷新

### AC-F003-003 · 查看右栏文件全文预览或导入 JSON

- 来源：PSC-001, PSC-006, PSC-008
- Given 用户在第 3 页点击任意文件节点或执行 JSON 配置导入/导出
- When 查看右栏文件全文预览或导入 JSON
- Then 右栏实时展示注入项目名/技术栈/当前语言路径后的完整文件正文并支持一键复制；非法 JSON 导入被安全拦截并提示中文错误（EX-03）
