## 五、页面骨架模式与通用交互规范

> 若本项目为管理后台 / 工作台类应用，可直接沿用下方默认规范；若为 C 端或工具型应用，请按实际形态调整。

### 5.1 典型页面骨架

| 页面类型 | 典型结构 | 适用场景 |
|---|---|---|
| 列表页 | 筛选区 + 工具条 + 数据表格 + 分页 | 高频查询与批量管理 |
| 表单页 | 页头 + 基础信息 + 明细区 + 固定底部操作栏 | 新增与编辑共享结构 |
| 详情页 | 状态区 + 信息卡片 + 明细/关联记录 + 底部操作栏 | 只读查看，动作按钮按状态动态展示 |
| 作业页 | 待处理任务 + 执行录入 + 异常备注 + 确认提交 | 高频执行类操作，强调效率与防错 |

### 5.2 通用交互规范

- 所有状态变更通过**明确动作按钮**触发（必要时配确认弹窗），**不在表单中直接下拉改状态**。
- 基础主数据**默认不提供物理删除**，统一用「停用」替代；停用后不可被新记录引用，历史记录保留完整数据。
- 关键流程确认/审核后**核心字段锁定**，仅备注类字段可修改。
- 历史记录中引用的档案信息采用**快照存储**，避免主数据修改污染历史账目。
- 必填项清晰标识；阻断类校验用字段下方错误提示，操作结果用轻量 Toast 反馈。
- 底部操作栏按钮顺序统一：**次要操作在左、主要操作在右**。

### 5.3 常用控件选型指引（按需裁剪）

| 场景 | 推荐控件 | 说明 |
|---|---|---|
| 选择已有档案 | 可搜索下拉选择器 | 支持按编码或名称检索 |
| 批量/多选业务对象 | 搜索选择弹窗 | 选中后自动回填关联只读信息 |
| 日期 / 区间筛选 | 日期选择器 / 区间选择器 | 按需提供快捷范围（今天 / 本周 / 本月） |
| 状态筛选（≥ 3 项） | Tab 栏或分段控件 | 比纯下拉更直观 |
| 金额 / 数量输入 | 数值输入框 | 明确精度、单位、正负约束与千分位格式 |
