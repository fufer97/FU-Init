## AI 使用说明

当你被要求处理本项目相关任务时：
1. **先读本文件（00）**——了解当前有哪些背景文件、哪些已就位、哪些待向用户确认。
2. **按需读取后续文件**——根据当前任务类型精准读取，避免无差别加载全部文档：
   - 写 PRD → 读 `01`、`02`、`05`、`07`、`08` + `template/` 下对应模板
   - 画业务流程 → 读 `02`、`03`、`06`
   - 定义字段与规则 → 读 `05`、`08` + 字段清单模板
   - 设计页面与原型 → 读 `01`（页面模式与交互规范）+ `07`（跨模块通则）
   - 设计状态机与权限 → 读 `05`、`06`、`07`
3. **业务规则以 `context/` 为准**——不要凭通用行业经验擅自猜测；未确认信息统一标注 `【待确认】`。

## 文件权威层级

`context/` > `template/` > `prd/`

- **`context/`**：业务事实、项目边界、设计约束——**最高权威**。若与模板或 PRD 冲突，以 `context/` 为准。
- **`template/`**：格式规范与输出模板——决定「怎么写、按什么结构输出」。
- **`prd/`**：需求产出物——**生成物，不是权威源**。修改全局规则必须回溯更新 `context/` 或 `template/`，不能只在单份 PRD 里改规则。
