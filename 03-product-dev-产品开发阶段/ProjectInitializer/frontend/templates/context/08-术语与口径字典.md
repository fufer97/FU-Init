# 08-术语与口径字典

> 统一本项目所有核心术语与计算口径，避免同一概念在不同文档、页面和代码中叫不同名字。AI 处理本项目任务时以此为准。

## 一、主数据与核心对象术语

| 术语 | 统一口径 | 禁止混用 |
|---|---|---|
| 【核心对象 A】 | 【待确认】 | 【待确认】 |
| 【核心对象 B】 | 【待确认】 | 【待确认】 |
| 启用 | 主数据可被下游新建业务记录引用的状态 | 激活、上架、开启、正常 |
| 停用 | 主数据不可被新建业务记录引用的状态（历史仍可见） | 禁用、冻结、下架、注销 |

## 四、通用操作动词规范

| 规范用词 | 含义 | 禁止混用 |
|---|---|---|
| 新增 | 创建新主数据或新业务记录 | 新建、创建、添加 |
| 编辑 | 修改已有记录 | 修改、更新、变更 |
| 查看 | 进入详情页只读展示 | 详情、预览 |
| 停用 | 终止主数据可被新记录引用 | 禁用、冻结、下架 |
| 启用 | 恢复主数据可被新记录引用 | 激活、解冻、上架 |
| 取消 | 撤回未产生下游执行的记录 | 作废 |
| 搜索 | 提交查询条件、按条件筛选 | 查询（作为按钮文案时禁用） |
| 导出 | 导出当前列表或筛选结果 | 下载、导出 Excel |
