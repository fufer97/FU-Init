## 拆分原则

- 根据当前目标选择业务任务、处理阶段或能力模块，以职责、可验证结果和迭代边界拆分。
- 阶段/模块写明输入、输出与消费方；Feature 不强制对应独立页面、服务或部署单元。
- 本表确认后是 Feature 边界、需求/PSC 归属和依赖的唯一事实源。
- 改边界、增删或重排 Feature 时先说明影响并更新本表，按当前授权确认并记录依据。
