## 安装与构建

在一次性临时目录运行：

```sh
npx --yes shadcn@4.21.0 init --template vite --base radix --preset nova --no-monorepo --name prototype-smoke --yes
cd prototype-smoke
npx --yes shadcn@4.21.0 add dialog --yes
npm run build
npm run dev -- --host 127.0.0.1 --port 5178 --strictPort
```

结果：工程与 Button/Dialog 组件创建成功，TypeScript 和 Vite 构建通过，本地服务启动成功。

初始化探索中发现 `--preset radix-nova` 被 CLI 拒绝；有效参数为 `--base radix --preset nova`。本安装说明已经使用后者；生成配置中的 `style: radix-nova` 与 CLI 参数不能混淆。

脚手架生成的 `vite.config.ts` 使用 `__dirname`，Vite 提示未来原生配置加载器不支持该写法。本次构建与运行均未被阻塞，没有为这条未来兼容提示改写上游脚手架。
