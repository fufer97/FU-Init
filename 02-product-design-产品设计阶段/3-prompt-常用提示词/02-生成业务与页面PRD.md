# 常用提示词 02：基于上下文与模板生成业务及页面 PRD

> **适用时机**：`1-context-业务上下文/` 已就绪，准备为某个具体业务模块生成字段清单、业务 PRD 与页面 Demo 版 PRD。

```plain
请先完整阅读：
1. AGENTS.md（严格遵守六大防跑偏约束）
2. 1-context-业务上下文/ 下的全部背景与规范文件
3. 2-template-输出模板/ 下的字段清单模板、PRD模板、前端Demo模板

现在我们推进【模块名称】的中观层与微观层设计：
第一步：请先基于业务上下文生成 4-prd-需求文档/【模块目录】/【模块名】字段清单.md；
第二步： strictly 基于该字段清单生成同目录下的 业务PRD.md 与各页面的 前端Demo版PRD.md。
约束：不得编造字段清单以外的字段；不确定的业务规则一律标注【待确认】。
```
