# 【页面名称】前端 Demo 版 PRD（页面实现规格）

> **关联业务 PRD**：同目录下的 `业务PRD.md`
> **权威字段源**：同目录下的 `【模块名】字段清单.md`（不得新增未登记字段）
> **视觉与体验基线**：遵循 `AGENTS.md` 中的前端风格约束与 `unslop` 规范（克制留白、清晰层级、真实业务数据）

---

## 1. 页面定位与进出路径
- **核心用户任务**：用户在此页面上要完成的一件核心事是什么？
- **进入入口**：从哪个页面/按钮点击进入？携带什么上下文参数？
- **完成出口**：操作成功后跳转到哪里，或在原位呈现什么可见反馈？

## 2. 页面空间布局与分区
- **顶栏 / 导航区**：【说明页面标题、步骤指示、返回或全局动作】
- **主工作区**：【说明核心表单、列表、画板或双栏工作台的宽度比例与排版】
- **辅助 / 预览区**：【说明右侧或底部实时反馈、摘要或预览内容】

## 3. 组件与字段绑定明细
| 分区 | 组件/字段中文名 | 绑定字段编码 (Key) | 控件类型 | 默认展示与占位 | 交互与联动规则 |
|---|---|---|---|---|---|
| 主工作区 | 【待补充】 | `field_key` | 单选胶囊 / 文本输入 / 树形勾选 | | |

## 4. 关键交互与状态反馈
- **初始/默认态**：打开页面时的默认选中项与立即可见的预览效果。
- **空状态 / 边界态**：当用户清空筛选项或未勾选必要项时的提示与禁用保护。
- **操作反馈**：点击核心按钮（如「导出 ZIP」「复制口令」）后的即时视觉反馈。
