# 前端第 1 页：图册介绍页（Atlas Editorial Landing）— Demo 版 PRD

> **关联业务 PRD**：`业务PRD.md`
> **权威字段源**：`项目初始化配置字段清单.md`
> **视觉参考基线**：Oil UI `#atlas` 画册编辑美学 + `unslop` 规范（暖纸画布、修长衬线标题 × 等宽编号 × 无衬线说明、无框 `16:10` 预览画板）

---

## 1. 页面定位与进出路径
- **核心用户任务**：让用户第一眼通过精装画册般的视觉图录理解「AI 时代五阶段项目初始化」的价值，并能**一键点选最契合自己当前场景的预设方案**进入配置工作台（或直接点击顶部/主按钮开始自由定制）。
- **进入入口**：打开 Web 应用默认首屏（视图状态 `activeStep = 'atlas'`，同时顶部常驻极简步骤切换栏，可随时在「`01 方案图册` / `02 全局配置` / `03 目录工作台与导出`」间切换）。
- **完成出口**：点击任一方案卡片（自动应用该预设的 `presetId`、`selectedStages`、`devMode`）并平滑切换至第 2 页「全局配置」（也可在卡片上直接点「直达目录工作台」跳至第 3 页）。

## 2. 视觉 Token 与布局规范（严格遵循 `unslop` + `#atlas`）
- **色彩体系（Warm Gallery Paper Ramp）**：
  - 页面画布底色：`#FAF9F6`（温润美术馆画册纸白）
  - 卡片画板衬底：`#F2F0EA` / `#EAE8E1`（微暖石膏灰，带 `1px solid #E2E1DC` 极细边）
  - 主文字与选中胶囊底色：`#17201B`（深墨绿黑）
  - 次级说明文字：`#5B615C`；弱化编号与辅助字：`#727772`
  - 顶栏右侧主操作胶囊底色：`#E6EBE4`（柔和鼠尾草浅绿，配 `#17201B` 深墨字）
- **字体排印对比**：
  - 眉题（Eyebrow）：12px 无衬线（如 `AI 时代软件工程基建 · 五阶段标准工作区`）
  - 主标题（H1）与卡片主名：28px～38px **高雅衬线体**（`'Instrument Serif', 'Playfair Display', 'Songti SC', 'Noto Serif SC', Georgia, serif`），字重 400～500，绝不使用粗黑 800 字重或彩色渐变字
  - 索引编号（`W01`、`W02`、`W03`）：13px **等宽字体**（`ui-monospace, SFMono-Regular, Menlo, monospace`）
- **布局结构**：
  1. **Sticky 极简顶栏（56px 高，底部 `1px solid #17201B` 细黑线）**：左侧品牌标识 `Project Atlas · 一键项目初始化`，中部三步导航锚点，右侧「开始自由配置 →」鼠尾草绿胶囊按钮。
  2. **画册序言与胶囊筛选条**：左对齐眉题 + 衬线大标题「不同工程阶段的标准化 AI 工作区图册」，下方水平排列圆角药丸筛选胶囊（`全部方案 3`、`设计+开发联动 1`、`产品设计专精 1`、`FDE 工程交付 1`）。
  3. **响应式无框画册卡片网格（桌面端 3 列 / 平板 2 列，间距 32px）**：每张卡片由上方 `16:10` 圆角（`14px`）实时架构预览画板 + 下方极简三行图录题注组成。

## 4. 关键交互
- **点击筛选胶囊**：平滑过滤下方卡片，当前激活胶囊切换为 `#17201B` 实心黑底配 `#FAF9F6` 浅纸色文字。
- **点击任一卡片**：自动将该方案对应的 `selectedStages` 与 `devMode` 载入全局状态，并推进到第 2 页「全局配置」（卡片底部同时提供「直接预览目录树 →」快捷动作，可一步跳到第 3 页）。
