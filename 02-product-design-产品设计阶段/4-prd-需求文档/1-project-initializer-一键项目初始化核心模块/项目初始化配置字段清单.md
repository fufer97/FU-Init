# 一键项目初始化核心模块 — 权威字段清单

> **单一权威源声明**：本文件是「一键项目初始化」所有业务 PRD、三页前端 Demo 版 PRD 与后续 `03-product-dev-产品开发阶段` 的**唯一字段事实源**。

---

## 1. 全局配置对象（`ProjectInitConfig`）

| 序号 | 中文显示名 | 字段编码 (Key) | 数据类型 | 必填 | 默认值 | 枚举值 / 数据来源 | 业务校验与联动规则 |
| :---: |---|---|---| :---: |---|---|---|
| 1 | 预设方案标识 | `presetId` | Enum | 否 | `'design-to-dev'` | `'pm-design'`（产品设计专精） / `'design-to-dev'`（设计→开发联动） / `'fde-full-dev'`（完整 FDE 开发交付） / `'custom'` | 在第 1 页点击图册卡片时自动填充对应阶段组合；用户手动改阶段后变为 `'custom'` |
| 2 | 目录语言模式 | `language` | Enum | 是 | `'bilingual'` | `'zh'`（纯中文） / `'en'`（纯英文） / `'bilingual'`（中文+英文） | 切换时所有 `numbered: true` 的业务目录实时按规则重算显示名；工程固定目录不受影响 |
| 3 | 主力 Agent | `primaryAgent` | Enum | 是 | `'antigravity'` | `'antigravity'`（Antigravity 2.0） / `'generic'`（通用标准 Agent） | 选 `'antigravity'` 时生成 `.agents/rules/*.md` 与 `.antigravityignore`；选 `'generic'` 时将规则并入阶段 `AGENTS.md` |
| 4 | 所选工程阶段 | `selectedStages` | Array\<StageId\> | 是 | `['02', '03']` | `'01'`（需求收集）/ `'02'`（产品设计）/ `'03'`（产品开发）/ `'04'`（产品测试）/ `'05'`（产品运维） | 至少勾选 1 个阶段；固定按 `01`→`05` 顺序排列 |
| 5 | 开发阶段模式 | `devMode` | Enum | 是 | `'linked'` | `'full'`（完整开发模式，12 技能） / `'linked'`（精简开发模式，6 技能，跳过 PRD） | **自动规则**：同时含 `'02'` 与 `'03'` 时自动设为 `'linked'`；含 `'03'` 但不含 `'02'` 时默认 `'full'`；支持用户通过 `devModeOverride` 手动切换 |
| 6 | 手动锁定开发模式 | `devModeOverride` | Boolean | 是 | `false` | `true` / `false` | 当用户仅选 `'03'` 但已有外部设计稿时，可手动切为 `'linked'` |
| 7 | 项目名称 | `projectName` | String(64) | 否 | `''` | 用户可选输入（如 `强盛科技进销存`） | 填写后自动注入各阶段 `AGENTS.md`、`01-项目背景.md` 与 `项目启动.md`；未填则写入 `【待补充：项目名称】` |
| 8 | 英文工程目录名 | `projectSlug` | String(48) | 否 | `'MyProject'` | 用户可选输入 PascalCase（如 `OrderFulfillment`） | 仅在包含 `'03'` 阶段时提示，写入 `03` 阶段 `AGENTS.md` 与 `项目启动.md` 示例命令中 |
| 9 | 一句话项目定位 | `projectSummary` | String(200) | 否 | `''` | 用户可选输入 | 填写后注入模板；未填则写入 `【待补充：一句话说明项目解决什么问题】` |
| 10 | 技术栈描述 | `techStack` | String(200) | 否 | `''` | 用户可选输入（如 `React + TypeScript + Tailwind CSS`） | 填写后同时注入 `02` 与 `03` 的文档模板，保持设计/开发口径一致 |

## 2. 目录树节点对象（`TreeNode`）

| 序号 | 中文显示名 | 字段编码 (Key) | 数据类型 | 必填 | 默认值 | 数据来源 / 枚举值定义 | 业务校验与联动规则 |
| :---: |---|---|---| :---: |---|---|---|
| 1 | 节点唯一标识 | `id` | String | 是 | 系统生成 | 树内唯一 ID | 用于勾选、排序、重命名与预览定位 |
| 2 | 所属阶段编号 | `stageId` | StageId | 是 | — | `'01'` ~ `'05'` | 归属哪个 1 级阶段目录 |
| 3 | 节点类型 | `kind` | Enum | 是 | `'folder'` | `'folder'`（文件夹） / `'file'`（文件） | 决定图标、是否可包含子节点及打包行为 |
| 4 | 节点层级深度 | `level` | Number | 是 | — | `1`（阶段层）/ `2`（阶段内工作区层）/ `3`（业务模块层）/ `4+` | `level >= 3` 的文件夹在打包时自动生成导航 `README.md`；`level == 2` 空文件夹自动写入 `.gitkeep` |
| 5 | 中文名称 | `nameZh` | String | 是 | — | 预设或用户自定义 | 中文模式与双语模式使用 |
| 6 | 英文名称 | `nameEn` | String | 是 | — | kebab-case 或固定文件名 | 英文模式与双语模式（`nameEn-nameZh`）使用 |
| 7 | 是否参与自动编号 | `numbered` | Boolean | 是 | `true` | 普通业务文件夹为 `true`；`Raw/`、`.agents/`、`AGENTS.md`、`.antigravityignore` 等为 `false` | `numbered: true` 的同级已勾选文件夹按当前排列顺序动态计算 `1-`、`2-` 前缀（1 级阶段固定用 `01-`~`05-`） |
| 8 | 是否勾选启用 | `checked` | Boolean | 是 | `true` | 用户勾选状态 | 取消勾选后不进入导出 ZIP，且同级后续节点序号自动前移重算 |
| 9 | 是否锁定不可取消 | `locked` | Boolean | 是 | `false` | 核心入口文件（如阶段 `AGENTS.md`、`Raw/`）为 `true` | 锁定节点保持勾选，保障 Agent 工作区最低可用契约 |
| 10 | 是否为用户自定义节点 | `isCustom` | Boolean | 是 | `false` | 用户在树形工作台点击「新增文件夹/文件」创建 | 支持重命名与删除 |
| 11 | 节点职责简介 | `description` | String | 是 | — | 一句话用途说明 | 用于 UI 悬停/副标题展示，并自动汇总写入上级 `AGENTS.md` 或 `README.md` 索引表 |
| 12 | 文件内容模板键 | `templateKey` | String | 否 | `null` | 对应内置模板或 Skill 资产路径 | 点击文件节点时，右侧实时渲染注入 `ProjectInitConfig` 后的真实文件内容 |
