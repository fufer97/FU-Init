# 前端第 2 页：全局配置页（Global Stage & Agent Config）— Demo 版 PRD

> **关联业务 PRD**：`业务PRD.md`
> **权威字段源**：`项目初始化配置字段清单.md`
> **视觉基线**：沿用 `#atlas` 暖纸画册风格，左侧结构化配置表单，右侧实时配置摘要卡与双模式流程图

---

## 1. 页面定位与进出路径
- **核心用户任务**：完成项目的三大必填结构配置（**目录语言、主力 Agent、涉及软件工程阶段**），查看或手动切换「开发阶段双模式（完整 12 技能 vs 精简 6 技能）」，并按需选填项目基础元信息。
- **进入入口**：从第 1 页点击方案卡片或「开始自由配置 →」进入。
- **完成出口**：点击底部或右侧主按钮「下一步：定制目录树与预览文件 →」进入第 3 页；或点击顶部「导入已有 JSON 配置」一键恢复历史配置。

## 2. 页面分区与字段承接明细

| 分区 | 控件标题 | 绑定字段 (`Key`) | 交互组件形态 | 业务规则与视觉反馈 |
|---|---|---|---|---|
| **① 目录语言与主力 Agent** | 目录命名语言 | `language` | 三选一药丸分段控制器 | `中文+英文（推荐：1-context-业务上下文）` / `纯中文（1-业务上下文）` / `纯英文（1-context）`，下方即时显示一行真实路径示例 |
| 同上 | 主力 Agent | `primaryAgent` | 二选一画册卡片单选 | `Antigravity 2.0（推荐）`（自动生成 `.agents/rules/`、`.agents/skills/`、`.antigravityignore`） vs `通用标准 Agent`（规则自动合入 `AGENTS.md`） |
| **② 软件工程五阶段选择（多选）** | 涉及阶段 | `selectedStages` | 5 张带 `01`~`05` 等宽编号的横向勾选卡 | • `01-需求收集阶段`（轻量骨架）<br>• `02-产品设计阶段`（★深度内置：防跑偏约束 + 三大模板）<br>• `03-产品开发阶段`（★深度内置：FDE 工程规范 + 双模式 Skills）<br>• `04-产品测试阶段`（轻量骨架）<br>• `05-产品运维阶段`（轻量骨架）<br>至少保留 1 项勾选 |
| **③ 开发阶段双模式智能横幅** | 开发模式与手动覆写 | `devMode` + `devModeOverride` | 动态状态横幅 + 切换开关 | • 当同时勾选 `02 + 03` 时：显示墨绿横幅 `⚡ 已自动启用【精简开发模式（6 核心技能）】：02 阶段的 PRD 与原型可直接放入 03 的 Raw/，自动跳过需求清洗、原型与 docs/PRD.md`<br>• 当仅选 `03`（无 `02`）时：默认显示 `📦 当前为【完整开发模式（12 通用技能）】`，并在右侧提供开关 `「我已有现成的外部 PRD / 设计稿 → 切换为精简开发模式（6 技能）」` |
| **④ 项目基础元信息（全部可选）** | 项目名称 / 英文工程名 / 一句话简介 / 技术栈 | `projectName`、`projectSlug`、`projectSummary`、`techStack` | 2×2 干净输入框（标明“选填，留空将保留【待补充】由本地 Agent 对话补全”） | 输入后实时同步到第 3 页所有 `AGENTS.md`、`01-项目背景.md` 与 `项目启动.md` 预览中，根治设计/开发技术栈口径不一 |

## 3. 右侧实时摘要面板与快捷动作
- **当前方案摘要卡**：实时展示将要生成的 1 级阶段文件夹列表、将打包的 Skills 数量（`6 个精简技能` / `12 个完整技能` / `0 个`）、以及本地 Agent 专属配置文件清单。
- **配置复用工具栏**：提供「导出当前配置 JSON」与「导入 JSON 配置」按钮，方便个人或团队保存常用初始化配方。
