# 前端第 3 页：树形工作台与导出（Tree Workbench & ZIP Export）— Demo 版 PRD

> **关联业务 PRD**：`业务PRD.md`
> **权威字段源**：`项目初始化配置字段清单.md`
> **视觉基线**：左树右预览双栏精密工作台（Quiet Chrome，高信息密度，4px 间距网格，无多余装饰）

---

## 1. 页面定位与进出路径
- **核心用户任务**：在所选阶段的树形结构下，勾选需要的 2/3 级文件夹与文件、手动调整同级顺序（实时重算 `1-`、`2-` 序号）、按需新增或重命名自定义节点，并在右侧实时检视最终目录树与任意文件的完整文本内容，确认无误后一键导出 **ZIP 初始化包**。
- **进入入口**：从第 2 页点击「下一步」或从第 1/2 页顶部导航切入。
- **完成出口**：点击右上角或底部主按钮「打包下载初始化 ZIP」，弹出包含 **本地 Agent 启动口令（一键复制）** 与 **WorkBuddy 沙箱下载逃生舱** 的交付弹窗。

## 2. 双栏工作台布局与交互规则

### 2.1 左栏：阶段树形轻编辑器（占宽 45%）
1. **阶段分组折叠树**：按所选 `01`～`05` 阶段依次展开。
2. **节点隐藏规则（防视觉噪音）**：
   - 树形勾选列表中**不显示** 3 级及以下自动生成的 `README.md` 与 2 级空目录的 `.gitkeep`（在顶部提示条注明：`注：打包时将自动为所有 3 级及以下文件夹生成导航 README.md`）；
   - `.agents/skills/` 下根据当前 `devMode` 自动展示对应的 6 个（精简模式）或 12 个（完整模式）技能文件夹，用户也可按需单独勾选/取消某个可选技能。
3. **节点行级操作栏（悬停或选中时显现）**：
   - **勾选框**：切换 `checked`（锁定节点如 `AGENTS.md`、`Raw/` 置灰不可取消）；**取消或勾选任一 `numbered: true` 的目录时，同级后续目录的 `1-`、`2-` 序号立即自动重排**！
   - **上移 `↑` / 下移 `↓` 按钮**：在同级兄弟节点间调整顺序，**序号立即重新从 `1-` 编号**，右侧 `AGENTS.md` 索引表同步刷新！
   - **新增子节点 `+`（仅文件夹节点可见）**：弹出轻量行内输入框，填写「中文名」「英文名」并选择「文件夹 / Markdown 文件」，在当前目录下新增自定义节点（若新增在 2 级目录下即为 3 级文件夹，打包时同样自动为其生成 `README.md`）。
   - **重命名 / 删除（自定义节点可删除）**：支持随时微调目录或文件名。

### 2.2 右栏：实时双模预览器（占宽 55%）
顶部提供两个预览页签：
1. **页签 A：`完整产出目录树（含自动 README）`**：
   - 以清晰的等宽树状图展示最终 ZIP 解压后的**真实全貌**（包含顶层 `项目启动.md`、各阶段目录、以及所有自动补齐的 3 级 `README.md` 和 `.gitkeep` 标记），并用不同颜色小标签标出 `[自动生成 README]`、`[精简模式 6 Skills]`、`[Antigravity 专属]`。
2. **页签 B：`文件内容实时预览`**：
   - 在左栏或右栏点击任意文件（如 `项目启动.md`、`02-.../AGENTS.md`、`03-.../AGENTS.md`、`.agents/rules/engineering-principles.md`、`Raw/HANDOFF.md`、`PRD模板.md` 或任意 `SKILL.md`），立即展示将要写入 ZIP 的**完整真实文本内容**（已实时替换项目名、技术栈、当前语言目录名与序号），右上角提供「复制单文件全文」按钮。

## 3. 导出 ZIP 与交付弹窗（含 WorkBuddy 沙箱逃生舱）
点击「打包下载初始化 ZIP」后：
1. **立即触发浏览器本地 JSZip 打包下载**：文件名默认为 `<projectSlug或project-init>-scaffold.zip`，**ZIP 顶层不含 0 级项目文件夹**，直接平铺所选 1 级阶段文件夹 + `项目启动.md`。
2. **弹出「初始化交付与本地 Agent 接管指引」抽屉/弹窗**，包含三块内容：
   - **步骤 ① 解压指引**：将 ZIP 解压到你新建的 0 级项目文件夹（如 `XXX项目/`），用 Antigravity 2.0 直接打开对应的 1 级阶段目录作为工作区。
   - **步骤 ② 一键复制给本地 Agent 的开场白口令**：提供定制好的中文 Prompt，点击「一键复制口令」即可直接粘贴给本地 Antigravity 启动对话。
   - **步骤 ③ 沙箱下载兜底（WorkBuddy 预览器逃生舱）**：若在受限内嵌预览器中点击下载未响应，提供 **「一键复制本地自动建目录脚本（macOS/Linux 终端一键执行）」** 与 **「下载/复制 `项目启动.md` 单文件」**，确保在任何沙箱环境下 100% 都能顺利落地。
