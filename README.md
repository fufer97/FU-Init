# FU-Init · 一键项目初始化

> 快速构建 AI 工作区：按软件工程阶段生成规范目录、规则入口与自动化开发技能包，纯前端离线运行，一键导出 ZIP。

作者：**fufu**

---

## 核心特性

- **按岗位拆分独立工作区**：支持 `02-产品设计阶段` 与 `03-产品开发阶段`（`01`/`04`/`05` 预留扩展），支持「中文 / 英文 / 中文+英文」目录命名，并可自由增删、重命名与同级排序。
- **精简 / 完整双开发模式自动联动**：
  - 同时勾选产品设计与产品开发时，自动切换为 **精简模式（7 项核心技能）**，跳过重复需求整理与原型，直接承接上游设计稿；
  - 单独勾选产品开发时，自动切换为 **完整模式（13 项全部技能）**，覆盖从需求收集、原型确认到工程交付全流程。
- **零业务预设，即下即用**：只生成干净目录骨架、`.gitignore`、`AGENTS.md`、工作区规则与内置技能包，不预填假业务文档；解压后发送对话给本地 Agent 即可通过 `项目启动.md` 完成首次初始化。
- **单文件离线可用**：前端构建为完全自包含的单文件 HTML（无外部 CDN 依赖），可直接双击在浏览器打开，或单文件发布至 WorkBuddy 资料库 / 静态托管站点。

## 目录结构

```text
.
├── 02-product-design-产品设计阶段/     # 本项目自身的产品设计上下文与需求文档
└── 03-product-dev-产品开发阶段/
    ├── .agents/                       # 工程规范与 13 项内置开发技能源码
    ├── ProjectAtlas-一键项目初始化.html  # 开箱即用的单文件 HTML 成品
    └── ProjectInitializer/
        ├── docs/                      # 架构、规格与验收记录
        ├── evals/                     # 功能验收用例
        └── frontend/                  # React + TypeScript + Vite 单文件前端源码
```

## 本地二次开发与构建

需要 Node.js 18+：

```bash
cd "03-product-dev-产品开发阶段/ProjectInitializer/frontend"
npm install
npm test
npm run build
```

构建产物位于 `dist/index.html`，可同步覆盖 `03-product-dev-产品开发阶段/ProjectAtlas-一键项目初始化.html`。
